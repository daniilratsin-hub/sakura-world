# Sakura World — полный сайт магазина

Новый адаптивный сайт-магазин для Minecraft Paper / Spigot / Purpur.

## Что уже есть
- Главная страница в неоновом стиле Sakura.
- Каталог: привилегии, кейсы с заранее указанным содержимым, монеты, Sakura-токены.
- Поиск и фильтр по категориям.
- Корзина с подсчётом суммы.
- Форма оформления заказа; после настройки backend создаёт тестовую запись заказа без сбора банковских данных.
- `backend-config.js` — публичный адрес backend (никаких секретных ключей).
- Разделы FAQ, правила магазина и контакты.
- Отдельный серверный шаблон Node.js/Express для будущего подключения платёжного провайдера.
- Пример `.env.example`, проверка входящих webhook-подтверждений как отдельная точка интеграции.

## Важно перед публикацией
Сейчас платежи находятся в DEMO-режиме: сайт не принимает настоящие деньги и не выдаёт товары автоматически. Это специально — пока не выбран платёжный провайдер и не настроены его секретные ключи.

GitHub Pages может разместить только фронтенд. Для настоящей оплаты и автоматической выдачи нужен серверный backend, домен/HTTPS и подтверждение платежа от провайдера. Не вставляйте секретные ключи в `script.js` или другие публичные файлы.

Платёжный аккаунт должен оформить и контролировать совершеннолетний человек в соответствии с правилами выбранного провайдера. Никогда не собирайте номера карт, CVV или банковские пароли на своём сайте.

## Подключение backend к фронтенду
1. Разместите папку `server` на отдельном сервисе, который поддерживает Node.js и HTTPS.
2. Настройте `FRONTEND_ORIGIN` в `.env` на адрес GitHub Pages.
3. В `backend-config.js` укажите HTTPS-адрес backend в `window.SAKURA_API_BASE`.
4. Пока сервер возвращает DEMO-режим: создаётся только тестовый заказ. Реальные оплаты и выдача предметов не включены.

## Быстрый просмотр
Откройте `index.html` в браузере.

## Локальный запуск backend-шаблона
Требуется Node.js 20+.

```bash
cd server
cp .env.example .env
npm install
npm run dev
```

Сервер запускается в DEMO-режиме, пока не добавлена интеграция конкретного платёжного провайдера. `/api/health` проверяет состояние сервера, `/api/checkout` создаёт демонстрационный заказ, `/api/webhook` специально не подтверждает реальные оплаты без проверки подписи провайдера.

## Подключение Minecraft
В `server/README.md` описан следующий шаг: связать подтверждённые заказы с плагином Paper через безопасную очередь команд. Не запускайте команды из непроверенного пользовательского ввода.
