## Публикация на GitHub Pages
Загрузи содержимое папки проекта в корень репозитория и включи GitHub Pages для нужной ветки/папки. Фронтенд не содержит платёжных секретов.

## Важно о платежах
Сейчас сайт **не принимает реальные платежи и не выдаёт покупки автоматически**. `server/` — только начальная заготовка backend. Для настоящего магазина необходимо подключить платёжного провайдера, серверную проверку подписи webhook, постоянную базу заказов и защищённую интеграцию с Minecraft. Не размещай секретные ключи в GitHub Pages и не открывай RCON в интернет.

## Правила
`rules.html` содержит стартовые правила сервера, список запрещённых читов и модификаций, а также основные разрешённые визуальные моды. Перед запуском владелец должен проверить и при необходимости скорректировать их под реальные правила Sakura World.
